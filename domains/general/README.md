# General writing domain

The general domain supplies reusable skills for ordinary writing work before a
specialized genre or destination takes over.

## Index

The [generated skill index](../../index/README.md) is the maintained view for
this domain. The composition below explains when those skills work together.

## Composition

A common workflow is:

1. use `general-writing` to create or adapt the artifact;
2. use `writing-review` for purpose, evidence, audience, and structure;
3. use `ai-writing-review` for a separate prose-pattern diagnosis; and
4. use `writing-cleanup` to apply the accepted repairs.

Do not run all four automatically when one skill answers the request. Compose
them when separate drafting and independent review materially improve the
result.

## Planned extensions

Future skills may cover copywriting, books, research reports, white papers,
technical documentation, case studies, executive communications, email, and
social writing. Each should reuse the general source-fidelity and review
principles while adding domain-specific decisions.
