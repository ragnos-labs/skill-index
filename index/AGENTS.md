# Generated index instructions

Files in this directory are generated by `scripts/render_indexes.py`.

- Do not edit `skills.json` or `README.md` by hand.
- Change skill or domain records, review receipts, research packets, or skill
  files instead.
- Run `make index`, inspect the diff, then run `make check`.
- Keep generated output deterministic and free of timestamps that change when
  the maintained inputs do not.
